# react-native-unzip-http

Download individual files from a ZIP archive over HTTP.
iOS only.

This is almost a direct translation of https://github.com/saulpw/unzip-http
and uses https://github.com/stremovskyy/SwiftyDeflate to decompress Deflate'd data.

## Installation


```sh
npm install github:davidisaaclee/react-native-unzip-http
```
